Usage:
python run.py [mode] [directory to compare against] --ref [input.mid] --ref [input2.mid]

e.g. run.py s N:/Documents/Midi_collection --ref mysong.mid



Modes:

S - Embedding comparison

SM - Embedding comparison + additional focus on mood over texture

QS - Qualitative comparison

QH - Hybrid qualitive/embedding comparison

C - Check file integrity of directory and clean corrupted MIDIs
